# TII 保單理賠分析助手 (TII Policy Crawler & AI Claims Finder)

本專案是一個用來爬取中華民國保險事業發展中心 (TII) 的保單條款並結合 Google Gemini AI 進行理賠與手術比對分析的本地工具。

---

## 🛠️ 快速啟動指南 (Windows 本地部署)

我們為 Windows 環境配置了全自動的一鍵啟動腳本，使用極為便利。

### 1. 配置 AI 智慧分析 (選填)
如果您想要啟用 **AI 理賠手術比對**功能：
1. 用文字編輯器（如記事本、VS Code）打開本目錄下的 `local_env.bat`。
2. 將其中的 `YOUR_GEMINI_API_KEY` 替換為您的 **Google Gemini API 金鑰**：
   ```cmd
   set GEMINI_API_KEY=AIzaSyYourGeminiApiKeyHere...
   ```
*(若不設定 API 金鑰，系統在執行比對時會自動降級為本機的關鍵字文字比對，不影響基本功能。)*

### 2. 一鍵啟動服務
1. 直接按兩下按鈕執行目錄底下的 **`啟動服務.bat`**。
2. 腳本會自動：
   - 檢查並確保您的電腦已安裝 [Node.js](https://nodejs.org/) 環境。
   - 自動開啟瀏覽器並進入系統首頁：`http://localhost:3005`。
   - 啟動本地 Node.js 後端伺服器。
3. **結束服務**：只要直接關閉執行中的黑色命令提示字元 (Command Prompt) 視窗即可。

---

## 💡 主要功能特點

1. **SQLite 本地快取與持久化**：所有的保單搜尋與下載的 PDF 檔案都會存儲於本地 SQLite 資料庫（`tii_cache.db`）中。
2. **免驗證碼快取搜尋**：一旦某家保險公司的保單被下載過，其他人再次搜尋相同關鍵字時會**完全免去驗證碼**，瞬間加載。
3. **AI 理賠手術分析**：輸入特定理賠關鍵字（例如 `白內障`），系統會：
   - 自動讀取並解析 PDF 條款文字。
   - 透過 Gemini API 分析該疾病在臨床上的常見手術。
   - 對照保單條款與除外責任，生成清晰完整的 **理賠與否結論報告**。
